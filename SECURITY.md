# Security policy

## Preview status

No public vmcli binary release is available yet. Public API and guest SSH access
have not completed acceptance. See [the security guide](docs/security.md) for
release gates. Do not treat preview documentation as a security attestation.

## Reporting a vulnerability

Report vulnerabilities privately through the contact options on
[servas.ai](https://servas.ai). Do not open a public issue for security problems.
Include the affected release, client operating system, expected behavior and a
minimal reproduction. Remove tokens, credentials, customer data, account
identifiers and sensitive connection details before sharing diagnostics.

Once a public release is available, security fixes will target the latest public
version. Supported platforms and update instructions will be listed in its
release notes. No update schedule or automatic update is promised by this preview.
