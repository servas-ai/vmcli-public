# Installing vmcli

**Preview only: no public vmcli release is available yet. Public API and SSH access have not passed acceptance.**

Start with [installation and release prerequisites](installation.md). That page describes the planned public downloads, supported-platform goals and required Ed25519 signature and SHA-256 checks. It intentionally contains no executable installation recipe or invented release version.

- [Configuration preview](configuration.md): intended public API and Zitadel identity path; device flow and `vmcli env` remain planned.
- [Usage preview](usage.md): source-checked lifecycle command syntax for use after release and acceptance.
- [Troubleshooting preview](troubleshooting.md): verification failures, release boundaries and current error meanings.

Customer installation is intended to work without `gh`, private repository access, VPN, Tailscale or API keys. Linux and macOS clients are planned; Windows clients are later and not approved. Initial customer guest VMs are Linux only.
